🌦️ Cloud9ja Weather Dashboard

A modern, responsive weather application built with React, Zustand, and TailwindCSS.
It fetches real-time weather data from multiple APIs, allows you to search for cities, save favorites, and switch between light/dark themes.

🚀 Features

🔍 Search Weather by city name.

📍 Get Weather by Location (geolocation support).

🕒 Hourly & Daily Forecasts with clean UI.

💜 Save Favorite Cities (persisted in localStorage).

🗑 Remove or Clear Saved Cities.

🌙 Dark/Light Mode Toggle with Zustand state.

📱 Responsive Design using TailwindCSS.

🛠️ Tech Stack

React – UI library

Zustand – lightweight state management

TailwindCSS – styling

Axios – API requests

React Router – navigation

APIs used:

Weatherbit
 → Current & daily forecasts

OpenWeather
 → Coordinates lookup

Open-Meteo
 → Hourly forecast
